
# Wine Quality Chemistry Explorer & Grader

## About the Project
An interactive machine learning application for exploring
physicochemical wine properties and predicting quality scores.

## Features
- Red and white wine dataset exploration
- Interactive chemistry visualizations
- Correlation heatmap
- Random Forest regression
- Gradient Boosting regression
- Model performance comparison
- Wine quality prediction form

## Technologies
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Plotly

## Dataset
UCI Wine Quality Dataset:
https://archive.ics.uci.edu/dataset/186/wine+quality

## Run Locally
Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Disclaimer
Predictions are estimates based on dataset patterns.
They are not laboratory measurements or safety certifications.
